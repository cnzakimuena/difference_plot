# Difference Plot
Script to generate a difference plot. The plot uses the chick weight dataset for demonstration. 

The dataset used for demonstration is featured in the following publication:

Crowder, M. J., & Hand, D. J. (1990). Analysis of repeated measures (Vol. 41). CRC Press.

installation:

```bash
pip install -r requirements.txt
```

usage:

```bash
python difference_plot.py
```
